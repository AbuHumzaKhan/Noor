# Noor Roadmap

## Phase 0 — Foundation
- Repository architecture
- Project mind
- Skill catalog
- Tool registry
- Permission policy
- Execution and verification boundaries
- Documentation and contribution rules

## V1 — Reliable partner
- Requirement understanding
- Project/context inspection
- Skill discovery and selection
- Controlled coding tools
- Python/SQL/MySQL/web/JSON/Excel/Power BI skill executors
- Data profiling, cleaning and analysis
- Git/GitHub workflow support
- Test and diagnostics integration
- Persistent user-approved memory
- Interactive chat UI
- Noor orb / workspace presence

## V1.x — Multi-repository intelligence
- Repository discovery
- Capability manifests
- License-aware source ingestion
- Adapter framework
- Versioned integrations
- Capability benchmarking

## V2 — Advanced agentic workflows
- Long-running verified workflows
- Project watchers
- Multi-step task execution
- Browser and desktop adapters
- Research workflows
- Cross-repository synthesis
- Failure recovery

## V3 — Mature autonomous partner
- Stronger planning and verification loops
- Local-first execution where practical
- Rich project observability
- Policy-driven autonomy
- Extensible skill marketplace/registry

Every phase is validated through tests and real project tasks before the next capability layer is considered complete.
