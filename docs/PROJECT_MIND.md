# Noor — Project Mind

## Purpose
Noor is an autonomous multi-repository AI development partner designed to understand project requirements, plan work, modify code, validate changes, and continuously improve its capabilities while preserving user control and repository safety.

## Development methodology
- Agile delivery
- Prototyping and incremental validation
- Evidence-driven implementation
- Small, reversible changes
- Automated verification before completion

## Core loop
1. Understand requirement
2. Inspect repository and project context
3. Discover relevant skills/tools/repositories
4. Select an execution strategy
5. Plan changes
6. Request/validate permissions where required
7. Execute controlled changes
8. Run tests and diagnostics
9. Verify outcomes
10. Document the change

## Design principles
- Local-first where practical
- Provider-agnostic integrations
- Least privilege
- Explicit approval for material-risk actions
- No secrets in source control
- Reversible operations
- Observable execution
- Modular skills and tool adapters
- Multi-repository capability discovery without blindly copying external code

## Initial capability domains
- Coding and software engineering
- Data analysis and BI
- SQL/MySQL
- Python
- Web development
- Excel formulas
- Power BI/DAX/M
- Git/GitHub workflows
- Research
- Browser automation
- File operations
- Project planning
- Diagnostics
- Memory/context
- Security and permissions
- Voice/UI integration

## V1 direction
V1 focuses on establishing the architecture, skill registry, tool routing, execution safety, verification, repository integration, and a usable interactive interface. Advanced autonomy is delivered incrementally rather than by enabling uncontrolled self-modification.
